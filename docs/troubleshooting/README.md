# [TS-000] 제목 (예: GitHub API 연동 시 Rate Limit 발생 이슈)

## 1. 배경 및 현상 (Background & Symptoms)
- 어떤 작업을 하던 중 문제가 발생했는지 기술함.
- 에러 로그, 스크린샷, 혹은 기대했던 결과와 실제 결과의 차이를 명시함.

## 2. 원인 분석 및 가설 (Root Cause Analysis)
- 로그 분석, 코드 디버깅 등을 통해 파악한 근본 원인을 작성함.
- "이런 이유 때문에 문제가 발생했을 것"이라는 가설을 세움.

## 3. 시도한 해결책 (Attempted Solutions)
- 문제를 해결하기 위해 시도했던 여러 가지 방법들을 나열함.
- 각 방법이 왜 실패했는지, 혹은 어떤 부분에서 부족했는지 기록함.

## 4. 최종 해결 방법 (Final Solution)
- 실제로 문제를 해결한 구체적인 방법과 코드를 작성함.

## 5. 결과 및 교훈 (Results & Retrospective)
- 해결 후 시스템의 상태 변화(성능 향상, 에러 소멸 등)를 기록함.
- 이 과정을 통해 새롭게 알게 된 점이나 향후 방지 대책을 작성함.
