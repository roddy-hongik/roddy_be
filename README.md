## 📖 1. 프로젝트 소개
**Roddy**는 개발자 지망생 및 주니어 개발자를 위한 **개인 맞춤형 전공/커리어 설계 및 로드맵 가이드 서비스**입니다. 
사용자의 GitHub 리포지토리와 이력서를 분석하여 현재의 기술 스택 수준(Tier)을 진단하고, 실제 채용 공고(Trend)와 합격자 데이터를 바탕으로 부족한 기술과 다음 학습 방향을 'Graph' 형태로 시각화하여 추천해 줍니다.
